How to Calculate Percentage Increase

A percentage increase measures how much a value has grown relative to its original amount. It's expressed as a positive percentage and is one of the most common calculations in everyday life — from salary raises and price changes to population growth and investment returns.

The Percentage Increase Formula

% Increase = ((New Value − Original Value) ÷ Original Value) × 100

Step-by-Step Example

  • Identify the original value and the new value. Example: salary increased from $50,000 to $57,500.
  • Subtract: New − Original = $57,500 − $50,000 = $7,500
  • Divide by original: $7,500 ÷ $50,000 = 0.15
  • Multiply by 100: 0.15 × 100 = 15% increase

How to Increase a Number by a Percentage

To find the new value after a percentage increase, use: New Value = Original × (1 + %/100). For example, to increase $200 by 15%: $200 × 1.15 = $230.

💡 Tip: To quickly increase a value by 10%, simply add one-tenth of it. To increase by 25%, add one-quarter. These mental shortcuts work great for common percentages.

Frequently Asked Questions

How do I calculate percentage increase?
Use the formula: % Increase = ((New Value − Old Value) ÷ Old Value) × 100. For example, from 50 to 75: ((75−50)/50) × 100 = 50% increase.
What if the result is negative?
A negative result means the value actually decreased. In that case, you should use our percentage decrease calculator for correct framing.
