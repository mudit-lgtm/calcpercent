Percentage Decrease Calculator

Find the percentage decrease between two numbers, or calculate the new value after applying a percentage decrease.

% Decrease = ((Original − New) ÷ Original) × 100
New Value = Original × (1 − Percentage ÷ 100)

How to Calculate Percentage Decrease

A percentage decrease tells you how much a value has dropped relative to its original amount, expressed as a positive percentage. This calculation is used for price drops, weight loss, profit decline, and many other real-world scenarios.

The Percentage Decrease Formula

% Decrease = ((Original Value − New Value) ÷ Original Value) × 100

Step-by-Step Example

  • Identify the original and new lower values. Example: a product dropped from $80 to $60.
  • Subtract: Original − New = $80 − $60 = $20
  • Divide by original: $20 ÷ $80 = 0.25
  • Multiply by 100: 0.25 × 100 = 25% decrease

Decreasing a Value by a Percentage

To find the new value after a percentage decrease: New Value = Original × (1 − %/100). For example, 25% off $200 = $200 × 0.75 = $150.

Frequently Asked Questions

How do you calculate percentage decrease?
% Decrease = ((Original − New) ÷ Original) × 100. From 100 to 75: ((100−75)/100) × 100 = 25% decrease.
What is the difference between percentage decrease and percentage change?
Percentage decrease only applies when the value drops and returns a positive number. Percentage change can be positive or negative — see our percentage change calculator.
