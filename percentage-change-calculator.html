Percentage Change vs Percentage Difference

Percentage change compares a new value to an old value and has a direction — it tells you whether something increased or decreased, and by how much. It's the most common percentage calculation in everyday life.

Percentage difference, on the other hand, measures the difference between two values without implying direction, using their average as the reference point. For that, see our percentage difference calculator.

The Percentage Change Formula

% Change = ((New Value − Old Value) ÷ Old Value) × 100

A positive result means an increase. A negative result means a decrease.

When to Use Percentage Change

  • Tracking financial performance over time (revenue, profit, costs)
  • Monitoring price changes in products or services
  • Measuring growth in population, subscribers, or users
  • Comparing exam scores or athletic performance
  • Calculating year-over-year business metrics
💡 Tip: When the old value is negative, percentage change can seem counterintuitive. For example, a change from −$50 to −$25 would show a 50% "increase" even though the loss halved. Always check both values for context.

Frequently Asked Questions

How do I calculate percentage change?
% Change = ((New − Old) ÷ Old) × 100. Positive = increase, negative = decrease.
What's the difference between percentage change and percentage difference?
Percentage change uses the original (old) value as the reference and implies direction. Percentage difference uses the average of both values and is symmetric — neither value is "original." See our percentage difference calculator.
